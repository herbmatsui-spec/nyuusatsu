# 競合分析機能ガイド（仕様書類似度・難易度スコア・勝率予測）

デスクトップ版（`app_dashboard.py` → 競合分析タブ）とモバイル版（`app_mobile.py` → 競合分析）で利用できる、競合分析の高度化機能の使い方を説明します。

## 機能概要

| 機能 | タブ | 概要 |
|---|---|---|
| 競合企業分析 | 競合企業分析 | 落札履歴から企業別の勝率・落札件数を集計 |
| 仕様書類似検索 | 仕様書類似検索 | TF-IDF（文字2〜5グラム）コサイン類似度で類似案件を検索 |
| 予測・難易度 | 予測・難易度 | 入札難易度スコア（0〜100）と勝率スコア（0〜1）をルールベースで算出 |

LLMの呼び出しはありません。すべてローカル計算（scikit-learn + SQLAlchemy）で完結します。

## 仕様書類似検索の使い方

1. 「案件IDまたはキーワード」に案件番号（例: `1`）またはキーワード（例: `橋梁`）を入力
2. 検索件数と最低類似度を調整
3. 「類似度検索」ボタンを押すと上位N件が進捗バー付きで表示される

表示列: 類似度スコア / 案件番号 / タイトル / 発注機関 / 公開日 / 落札会社

### 前提条件

- `bids.specification_text` または `specification_text_clean` に仕様書本文が保存されていること
- 検索対象は既定で直近の案件に限定されます（`config/prediction_model.yaml` の `time_window_months`）
- 事前ベクトル化済みキャッシュがある場合は自動で読み込まれます（`data/similarity_cache/tfidf_vectors.pkl`）

### ベクトルの事前構築（任意・大規模データ向け）

```bash
python scripts/build_specification_vectors.py
```

## 難易度スコア・勝率予測の見方

「予測・難易度」タブで案件を選択すると、次のウィジェットが表示されます。

- **入札難易度（0〜100）**: 予算額・資格要件数・納期のタイトさ・過去競争率・仕様書長さの重み付け平均
- **予測勝率（0〜100%）**: 自社過去勝率・難易度逆相関・同機関の落札傾向・資格一致度の重み付け平均
- **内訳バーチャート**: 各要因の寄与度（%）を棒グラフで表示

### スコアの根拠（信頼度表示）

各スコアの横の「ℹ️」ポップオーバーで次を確認できます。

- **根拠充足度**: 過去実績などの根拠データがどれだけ揃っていたか（0〜100%）
- 根拠がない要因は既定値（中立値）で補完しています。根拠が乏しいほどスコアの信頼性は下がります
- スコアは**統計的に校正されていない参考値**です。参加可否の判定や入札戦略の唯一の根拠にしないでください

### 勝率予測の注意

- 勝率スコアは自社名（またはシステム設定の既定自社）に紐づく履歴から算出します。自社データがない場合は参考値（低信頼）になります
- 資格要件の等級判定は全省庁統一資格の表記のみを保守的に解釈します

## フィードバックの送信

予測ウィジェットと類似検索結果の下にある「👍 / 👎」ボタンで評価を記録できます。記録内容（種別・案件ID・評価のみ、個人情報なし）は `data/prediction_feedback.sqlite3` に保存され、週次集計してモデル調整の参考にします。

## 管理画面でのチューニング（要権限）

管理画面（`app_admin.py`）の「予測モデルチューニング」セクションで、権限を持つ管理者のみが次を変更できます。

- 難易度スコアの要素別重み（合計100%に制約）
- 勝率予測の要素重み
- 類似検索の既定件数・しきい値・TF-IDFパラメータ

変更は `config/prediction_model.yaml` に保存され、次回起動時から反映されます。TF-IDFパラメータ変更後は「再ベクトル化」ボタンでベクトルキャッシュを再構築してください。

## バッチ事前計算（夜間ジョブ向け）

大規模データでは表示の高速化のため、事前計算した汎用スコア（市場平均・未校正・自社非依存）をDBに保存できます。

```bash
# ドライラン（書き込みなし・既定）
python scripts/update_bid_difficulty_scores.py
python scripts/update_win_predictions.py

# 反映（直近24ヶ月・全件）
python scripts/update_bid_difficulty_scores.py --apply
python scripts/update_win_predictions.py --apply
```

ダッシュボードは常にリアルタイム計算値を優先表示します（事前計算値は参考表示用）。

## 制限事項

- スコアはルールベースの参考推定であり、統計モデルによる確率ではありません
- 過去実績データが少ない案件ほど根拠充足度が下がります
- 類似度は文字n-gramベースのため、表記ゆれには比較的強いですが、意味的な同義性（言い換え）は判定できません

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 類似検索が0件 | 対象案件に `specification_text` があるか、時間窓（`time_window_months`）内か確認 |
| マイグレーションエラー | `alembic upgrade head` を実行（`competitive_analysis_v1` が適用済みか確認） |
| スコアが表示されない | 案件の予算・資格・納期などの基本情報が登録されているか確認（不足時は既定値で補完） |
